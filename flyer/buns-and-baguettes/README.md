# Buns & Baguettes – Flyer A5

Doppelseitiger A5-Flyer (148 × 210 mm) mit 3 mm Beschnitt.

- `export/buns-baguettes-flyer-A5-druck.pdf` – Druckdatei (154 × 216 mm, Seite 1 = Vorderseite, Seite 2 = Karte)
- `export/vorderseite.png`, `export/rueckseite.png` – Vorschau im Endformat
- `logo.svg` – Logo, aus dem Foto der Theke vektorisiert (Farbe per `currentColor`)
- `flyer.html` – Quelle; Schriften (Archivo, Noto Naskh Arabic, OFL) liegen in `fonts/`

Neu bauen: `pip install playwright && python3 render.py`
